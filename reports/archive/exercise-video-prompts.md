## Global Style Token (DO NOT MODIFY between exercises)

Every prompt opens with the same character/lighting/environment "STYLE" token so Kling generates a consistent series. The only thing that changes per exercise is the **MOVEMENT** sentence(s).

```
[STYLE] Masterpiece quality, high-quality realistic 3D animation, static locked
camera, wide full-body shot, premium minimalist gym with wooden floors and large
windows on the right side, soft natural daylight, clean luxury fitness aesthetic,
cinematic realism, 3-5 second seamless looping motion, physically realistic
movement, no camera motion, no visual clutter.

[CHARACTER] A fit athletic 25-year-old male, short dark hair, wearing a black
compression tank top and grey performance compression shorts, realistic
anatomy, natural proportions.

[NEGATIVE PROMPT] no blur, no jump cuts, no camera shake, no text overlays,
no UI elements, no other people, no flickering lights, no distorted limbs,
no extra fingers, no warped joints, no logo on clothing.
```

When you paste a prompt below into Kling AI, paste the `[STYLE]` and `[CHARACTER]` blocks first, then the per-exercise movement description.

## Generation Workflow

1. Open Kling AI.
2. Paste the global `[STYLE]`, `[CHARACTER]`, and `[NEGATIVE PROMPT]` blocks once.
3. Append the per-exercise **Movement** sentence(s) for the prompt you're generating.
4. Set duration to match the per-exercise note (3.0 s / 3.4 s / 3.8 s / 4.5 s / 5.0 s).
5. Render. If the loop seam is visible, regenerate with "seamless looping motion" emphasised.
6. Download as `.mp4` with the exact `Save As` filename (PascalCase, matching `_composeVideoUrl(slug)`).
7. Upload to Supabase Storage `exercises` bucket. The Phase 96 SQL inserts will resolve to the live URL automatically once the file lands.
